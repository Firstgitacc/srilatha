# Sreelatha Suragani Portfolio

Purple editorial portfolio redesigned to match the supplied client reference: dark plum background, lilac accents, rounded pill navigation, oversized condensed typography, modular bento cards, About view, and My Work showcase.

## Files
- `index.html` — complete responsive portfolio
- `resume.pdf` — downloadable resume
- `architecture.md` — design/structure notes

## Run
Open `index.html` in a browser. No build step is required. Tailwind CSS and Google Fonts load from CDN.

## Deploy
Works on GitHub Pages, Netlify, Vercel, or Azure Static Web Apps.
