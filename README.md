# Sreelatha Suragani — .NET Developer Portfolio

A single-page, production-ready static portfolio built from Sreelatha Suragani's resume.

## Theme

**IDE Framework / Azure Enterprise** — a premium dark interface inspired by Visual Studio and modern engineering dashboards. It combines IDE-style code tabs, a subtle animated network canvas, enterprise glass panels, architecture nodes, interactive project deep-dives, and an expandable career timeline.

The theme fits this profile because the resume combines long-term .NET engineering depth with technical leadership, Azure/cloud delivery, SaaS operations, production support, data lifecycle management, and stakeholder enablement.

## Stack

- HTML5
- Tailwind CSS via CDN
- Vanilla JavaScript
- No build step
- No framework dependency
- Responsive and accessible
- Works on GitHub Pages, Vercel, Netlify, Azure Static Web Apps, or any static web host

## Files

- `index.html` — complete portfolio with all CSS and JavaScript embedded
- `architecture.md` — content/UX architecture and design decisions

## Run locally

Open `index.html` directly in a browser, or serve the folder with any local static server.

Example:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Notes about project links

The resume describes enterprise/client projects. It does not provide public GitHub repositories or public demo URLs. The portfolio therefore shows **Private repo** and **Internal deployment** states instead of inventing links.
