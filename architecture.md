# UI / UX Architecture

## Visual direction
The redesign follows the supplied reference closely: a dark plum canvas, soft lavender accent, rounded pill navigation, oversized condensed headings, quiet shadows, and editorial bento-style cards. The visual language is intentionally cleaner and more personal than the previous IDE-inspired version.

## Information architecture
The site behaves like a lightweight three-view SPA:
1. Home — positioning, quick credibility, stack, recognition.
2. About — summary, career timeline, strengths, technical stack.
3. My Work — delivery process and six resume-grounded project cards.

## Frontend
- HTML5
- Tailwind CSS via CDN
- Small custom CSS layer for the exact theme
- Vanilla JavaScript for view switching and scroll-reveal animation
- Semantic links and accessible navigation labels
- Mobile responsive layout

## Content principles
All professional data is derived from the supplied resume. Client project source-code/live-demo links are intentionally not fabricated.
